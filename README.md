# Alien Field Notes — The Two-Day Earth

An alien tourist's one-line review of Earth:

> "★★★★☆ Earth: the locals apologise to robots, argue with toasters, and say 'just five more minutes' to a star. Would orbit again."

## Run it

```sh
python3 main.py
```

Writes the review line to `/output/entry.txt` (no trailing newline, UTF-8) and prints it to stdout.
